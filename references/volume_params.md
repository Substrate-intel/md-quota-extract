## 三类高危混用点（历史上最容易漏改）

1. **编码/章码正则前缀**（`20-\d`、`012\d{3}`、`12001`）：漏改 → **静默错配**（正则匹配 0 条或错条，产物悄悄缺失）——危害最大；
2. **转换层三件**（字号分级/水印字符集/页码标定）：漏改 → **md 源本身错**，下游全链带错且门控可能全绿（基线锚定的就是错源）；
3. **数量断言**（gate/finalize/smoke 里的 487/77/53）：漏改 → 门控恒红（危害=可见，能暴露）。

## 机械复核（开工门）

```bash
# 复制并替换参数后，在卷工作目录执行：
python check_volume_params.py <卷工作目录>/scripts
# 退出码 0 = 零残留可开工；非 0 = 逐条列出残留，禁止开工
```

检查项六类：路径/文件名、sha12 锚定、编码与章码正则、数量断言、页码偏移、卷特有文案。
新卷沉淀出的新检查项形态，须回写本 skill 的 CHECKS 清单（见 iteration-protocol.md）。
