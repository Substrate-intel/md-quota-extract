# OCR 双源形态卷端到端实录：新疆2020房建装饰上册（OCR PDF + 矢量原版 → 九门全绿）

> 本文档是 xj01 卷（《新疆维吾尔自治区房屋建筑与装饰工程消耗量定额（上册）》2020，357 页）的真实全过程
> 记录。**本卷是管线第一种 OCR 双源形态**（此前各卷均为可提取文本的 PDF/DOCX 源），新卷遇"官方 PDF
> 无文本层/仅有矢量绘画"时照此主线走。坑编号对应 pitfalls.md。参考实现：`sp/quota-extract-xj01/scripts/`。

## 与既有形态的差异（选型判据）

| 判据 | xj01 实测 | 结论 |
| --- | --- | --- |
| 官方原版 PDF 文本层 | 仅 11/337 页有（矢量绘画型） | 不能当文本源 |
| OCR 可搜索版 | 存在（224MB，全文本） | 文本源 |
| 表格网格 | 原版 `get_drawings()` 线段丰富 | 网格几何源=原版 |
| 书目性质 | 纯消耗量定额（无基价/费用行） | H1/H2 skip 口径（坑 54） |

**双源定版：OCR 版=文本源，矢量原版=网格几何/校核源**（坑 51）。9 个 Fz 字体目录页原版层不可靠，
rapidocr 渲染兜底盒缓存（out/ocr_fz_boxes.json，sha12 入锚点）。

## 全过程时间线（9 个里程碑）

### M0 预检与源定版
- input/official.pdf（sha12=c0df6c521745，357 页）+ input/ocr.pdf（sha12=73b2a976a7ac）；
- 页码口径：正文印刷页=物理页−21（扉页 P22=印1）；总说明 P6-8 印=物理−5；GB50353 P10-13 印=物理−9；目录 P14-20 无印页；
- 册结构：10 章（中文数字章码 一~十，items.chapter 同契约）、537 子目表 + 附表。

### M1 转换层：双源合璧 PDF→md（坑 51/52）
- 原版 drawings 线段聚类 → 表格网格（列界/行界）；OCR 版文本行按坐标 assign 进网格；
- 坑 52 伪影四连：竖线 `|`/`丨` 剥离（装配段）、名称/单位粘连 END_UT_M 双正则去粘连、
  裸令牌 BARE_UT（'kg 一'→'—'）、**守卫=仅消耗行执行剥离**（P39 单位行真值 100m2/10m3 回归实证）；
- 注文行过滤（名称以「注」开头且无单位格=表尾注释，防错录成消耗行）。
- 验收：md 413025 字符 / 538 表 / 竖线剥离 5 处；**注意忠实层两出口——md 文本之后还有 extract_md 产 blocks JSON（坑 53）**。

### M2 保真层：md→块结构
- md_extract_full.json：4421 块（3883 段落 + 538 表格）+ md_index.json（10 章、子目表 525/其他 13）；
- meta 五锚点自证：md/ocr_pdf/official_pdf/convert_script/ocr_fz_boxes 的 sha12。

### M3 子目层：1755 子目解析
- 单元判别链 + 组标题跨列复制 + 竖跨合并 + 同前展开；单位行填充跳过 '—'（不覆盖 para『计量单位：见表』）；
- 验收：1755 子目（1-1~10-351 各章连续零空洞）/11073 消耗行/unit/work/name 零空；parse_issues=21（单位残缺 16+未分类等，语义留痕非缺陷）。

### M4 目录/条文层（坑 56/57）
- 目录：P14-20 双栏重组（x<280/≥280，栏内 y±6.5 聚簇）；章行无页码、下级行带全/半角括号页码；
  坑 57：2 字「附录」豁免扉页残余过滤、clean_leaders 仅清连续≥2 点导引保编号点、merge_page 跨行页码合并后重算层级；
  → **483 行**（章16/说明16/规则16/节82/子目337/附表15/附录1，其他行 0，页码零回退）；
- 条文：190 条（总说明 18 `^[一二三四五六七八九十]+、` + 规范 GB50353 61 `^\d+\.\d+\.\d+` + 章说明 47 + 计算规则 64）；
  计算规则内嵌引用表拍平 `【表】`+`；`/`｜` 入条（24 条带表，坑 56）。

### M5 落库

### M6 造价核验（坑 54）
